## Implement (diagnostic-only - labeled)

**Change stays in WPF `RemoteMicSender` only. Audio path behavior unchanged** (same cushion, same paced send, same drop/underrun handling, same MSA1).

1. **Immediate (or tightly rate-limited) EVENT lines** when:
   - **Every underrun** (`TryTake` fails / `_underruns` increments).
   - **Every overflow drop** (callback discarded / `_ringDrops` increments). Prefer one line per dropped callback (include frames dropped), not per sample.
   - **Low cushion / low occupancy**: when `_ringCount` falls below a clear threshold after armed - e.g. **under half cushion** / **under ~30 ms** (~**1440** frames @ 48 kHz). Rate-limit this (e.g. at most ~1 every 50-100 ms, or rising-edge only while below threshold) so a sustained low cushion does not flood the log.
   - **Optional (if easy):** large **WaveIn enqueue gaps** - track last `OnDataAvailable` wall/Stopwatch time; if gap >> ~10-20 ms expected, log once per gap. Skip if awkward; do not restructure capture for this.

2. **Tag format (grep-friendly):**
   - `Mic TX EVENT underrun=...`
   - `Mic TX EVENT drop=...`
   - `Mic TX EVENT low_cushion=...`
   - optional `Mic TX EVENT wavein_gap=...`
   - Include in each EVENT line: **ms-precision local time or TX-relative ms** (e.g. `t=HH:mm:ss.fff` or `tx_ms=`), `ring=` (frames and/or ms), `pkts=` (packets sent so far), and the counter just incremented. Example shape (non-binding):  
     `Mic TX EVENT underrun=1 t=13:52:01.247 tx_ms=35102 ring=960/2880 (20ms) pkts=3510`

3. **Keep periodic summary** (first + every 500). Prefer adding ms / `ring=` occupancy on those lines too if cheap. Do **not** remove `peak=` / `drops=` / `underruns=`.

4. **Rate-limit** EVENT spam so a stuck underrun or full-ring storm cannot fill disk; still ensure a rare single bump (~once per 60 s TX) is **visible** as its own line.

5. Do **not** change: cushion ms, ring length, WaveIn buffers, send pacing, silence-vs-skip underrun policy, MSA1, port **9101**, Pi host.

### Suggested shape (non-binding)

- Helper `LogMicEvent(string kind, ...)` that formats `Mic TX EVENT {kind}=...` with `DateTime.Now:HH:mm:ss.fff` (or Stopwatch from first armed send) and current `_ringCount`.
- Call from the underrun path in `SendLoop`, from the overflow branch in `OnDataAvailable`, and after `TryTake` / before send when `queued < LowCushionFrames` (e.g. `CushionFrames()/2`).
- Optional `_lastWaveInTicks` in `OnDataAvailable` for gap detection.
- Avoid logging under the hot path lock longer than needed - snapshot ints, then `Log?.Invoke` outside lock if practical.
