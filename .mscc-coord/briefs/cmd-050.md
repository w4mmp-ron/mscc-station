## What changed (Pi, Ron 2026-09-28)

- The shared `_all.deb` from `rpi/mscc-init-gui/` is now package **`mscc-init`**, version
  **1.0.18**: file **`mscc-init_1.0.18_all.deb`** (was `mscc-init-gui_<ver>_all.deb`).
  Ron: the old name was misleading, since the package now holds the CLI too.
- It has `Provides/Conflicts/Replaces: mscc-init-gui`, so `apt install ./mscc-init_*.deb`
  removes an installed `mscc-init-gui` by itself (checked with dpkg: 1.0.17 -> 1.0.18).
- The package holds both commands:
  - `mscc-init-gui`: desktop GUI, menu "MSCC Init" (unchanged).
  - `mscc-init`: **new Python text wizard** (`mscc_init_gui/cli.py`) for SSH / no desktop.
    Same prompts as the old C `mscc-init`, writes the same `~/.local/mscc` files through the
    GUI's `config.py` (keeps SWR_METER* lines). It replaces the old C `mscc-init` binary,
    which the Pi `mscc` .deb dropped in 1.0.47.
- GUI fix in 1.0.17 (included): the "MSCC servers are running" question now opens after the
  window is on screen. Before, it could stay hidden and leave a blank window.
- Folder `rpi/mscc-init-gui/`, the install path `/usr/share/mscc-init-gui` and the desktop
  file did not change.
