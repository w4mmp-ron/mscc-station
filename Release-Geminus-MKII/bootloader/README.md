# Omnia SDR Proficio

This project provides the booloader required by other projects.  Other firmware projects obtain the hex and elf files from this project. 
The bootloader project is static and seldom changes.

The project was built with PSoC Creator 4.x
http://www.cypress.com/

It is normal to get errors about missing files until you have built
the project for the first time.  This is because the generated files
have been excluded from the git repository.
