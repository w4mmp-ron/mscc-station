## The change

### 1. Port factory_seed to Linux ms-sdr

Add `linux/ms-sdr-linux/source/factory_seed.c` + `factory_seed.h` (from Windows as hypothesis):

- Paths: `/` separators; `mkdir`/`mkdir -p` style (`mkdir(path, 0755)` + parents); live = `My_getenv("HOME")`.
- `find_factory_root`: prefer `/usr/share/mscc/factory` (probe `…/iq/proficio-mkii/iq.ini`). Optional: next-to-exe fallback if useful; package path is primary.
- `Factory_seed_live_inis`: read `cal/LAST_LINE.txt`; if switching, stash live park-set into previous line; `place_cal_file` for iq / power / amplifier (amp default −99 when no factory amp file — match Windows); `seed_freq_if_missing` only; write `LAST_LINE`.
- `Factory_seed_reload_servers`: if live IQ/power replaced, send existing trans reload (`CMD_SET_IQ_DEFAULTS` / `CMD_SET_SDRCORE_TRANS_INITIALIZE`) — same idea as Windows.
- `Factory_reseed_live_file`: port and wire IQ Reset / FREQ CAL RESET like Windows if those Linux paths still create blank files — prefer factory→live for the current line. Do **not** mirror to park on reseed.
- **New:** `Factory_park_live_settings(void)` — for current `G_major_version` line, copy whichever of the three park files exist from live → `cal/<line>/`, write `LAST_LINE.txt`, log what was copied. Missing live files = skip (warn in log), not a hard fail. Unknown major = warn and no-op.
- Rules: **no** continuous live→parked mirrors; **no** exit auto-park.

Wire:

- `Makefile` `SRCS`: add `source/factory_seed.c`.
- After successful `srGetVersion` in `main.c` (and after fake major under `MS_SDR_NO_USB`), call `Factory_seed_live_inis()`.
- When network ready (same place Windows calls reload), call `Factory_seed_reload_servers()`.
- `usbavrcmd.h`: `#define CMD_SET_PARK_CAL_SETTINGS 0x29`
- `main-controller.c` `Command_Interface`: `case CMD_SET_PARK_CAL_SETTINGS:` → `Factory_park_live_settings();` (ignore payload or accept data=1). Prefer warning logs over stopping the radio.

Do **not** edit `SDRcore-trans` power ownership. ms-sdr may **copy** `power_cal.ini` for park/restore only.

`VERSION_MINOR` auto-bumps on `make` — fine. Deb version bump is separate (below).

### 2. Core + Avalonia Save settings → host park

- `IRadioService` + `UdpRadioService`: `ParkCalSettingsAsync()` → send `0x29` with short `1` (same pattern as other simple sets). No-op / early return if not started.
- Avalonia **0.6.70 → 0.6.71** (`MSCC.Avalonia.csproj` + `packaging/mscc-ui/DEBIAN/control`).
- UI: left rail under **LOG**, button **Save settings** (WPF placement). ToolTip ~ `Ask the host to park live cal for this radio.`
- On click: if not connected or firmware major unknown → **warning** dialog (connect radio first) — do not pretend success. If OK → `ParkCalSettingsAsync()`; info dialog that host was asked to park for line `<line>` (from major). **Do not** copy files under the client’s home as a substitute when remote.
- Optional short tip on QRP CAL / AMP CAL / TX IQ: `When done, press Save settings.` (cmd-059 wording). Keep tips brief.
- **Do not** add `CalPark.cs` client file copies. **Do not** edit WPF.

Optional partial: manually set `LAST_LINE.txt` to a *different* line, put distinct parked files under that other line and the target line, restart ms-sdr with radio attached, confirm stash + parked→live for the detected line (warn if flaky without second radio).
4. **Same line restart:** Restart servers without changing radio; live cal left alone (no unwanted parked→live overwrite).
5. Prefer **warnings** over lockouts; report any blocker (no radio, etc.) clearly.
