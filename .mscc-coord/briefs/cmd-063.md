### 2. Load File default folder

Edit **both** Ubuntu sources and keep the packaged helper in sync:

1. `linux/psoc-usb-bootload-linux/bootloader-gui.py` — `_load_file`
2. `linux/helpers/bootloader-gui` — must match (packager copies this into the `mscc` deb)
3. `rpi/psoc-usb-bootload-linux/bootloader-gui.py` — same default (Ron/Pi parity; small shared GUI fix)

Behavior:

```python
FIRMWARE_SHARE = Path("/usr/share/mscc/firmware")

def _default_load_dir() -> str | None:
    if FIRMWARE_SHARE.is_dir():
        return str(FIRMWARE_SHARE)
    return None

def _load_file(self) -> None:
    kwargs = dict(
        title="Open CYACD File",
        filetypes=[("cyacd file", "*.cyacd"), ("All files", "*.*")],
    )
    initial = _default_load_dir()
    if initial:
        kwargs["initialdir"] = initial
    else:
        self._log("Note: /usr/share/mscc/firmware missing — install mscc-firmware for packaged .cyacd files")
    path = filedialog.askopenfilename(**kwargs)
    ...
```

Rules:

- **Warning only** if the share dir is missing — still open the dialog.
- Never hard-error / disable Load File because the optional package is absent.
- Do not restrict `filetypes` to the package folder; user may browse anywhere.
- Optional: if `initialdir` points at the share root, that is enough (subfolders per radio). Do not auto-pick a `.cyacd`.

Bump nothing in Avalonia / Core / ms-sdr. No WPF.
