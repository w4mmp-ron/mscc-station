## 3. Bug: a new Host/Port is ignored until MSCC is closed

**Today:** `OnBackendIpChanged` / `OnBackendPortChanged` (MainViewModel.cs:5261 / :5272) save to `MSCC_Client.ini` (`SpectrumWaterfallSettings.UpdateServerAddress`, SpectrumWaterfallSettings.cs:1202). The comment at :5259-5260 says "NO re-initialization … User must stop and restart MSCC". The service is built once (MainViewModel.cs:1803-1812 → `new UdpRadioService(settings.RemoteIp, settings.RemotePort, settings.LocalPort)`). It keeps the address in `private readonly string _remoteIp` / `int _remotePort` (Core UdpRadioService.cs:20-21, set at :171-172). Every Start builds a fresh transport from those fields (`EnsureTransportForStart` :238 → `CreateTransport` :229, called from `StartAsync` :252). So Stop/Start reconnects to the **old** host.

**Fix (keep the same service instance):** MainWindow.xaml.cs subscribes to `vm.RadioService` events (e.g. :128-129, unsubscribed at :1032-1033), and the VM wires the service in its ctor. Replacing the object would drop those handlers, so don't.
1. Core `UdpRadioService`: make `_remoteIp` / `_remotePort` non-readonly and add `public bool SetRemoteEndpoint(string ip, int port)`. It returns false and does nothing if `_started`; otherwise it stores the values, logs ` Remote endpoint → ip:port`, and returns true if anything changed. The next `EnsureTransportForStart` uses them. This is additive: Avalonia doesn't call it and doesn't need to change. If you add it to `IRadioService`, that's additive too (UdpRadioService is the only implementation).
2. WPF `StartRadioService` (MainViewModel.cs:5304), just before `await _radioService.StartAsync(...)` (:5343): call `SetRemoteEndpoint(BackendIp, BackendPort)` when the service is a `UdpRadioService`, and log when the endpoint changed since the last connect. Don't touch LocalPort.
3. Leave `LaunchServersOnStart`, `EnsureLocalBackendHostnames` and Remote Audio behavior unchanged. The remote-audio gating (`IsRemoteAudioAllowed`) already reacts to BackendIp.
4. Update the comment at :5259-5260. Then apply the A12 text above (tooltip + popup + log).
