## The change

### 1. Windows ms-sdr — park opcode + Factory_park_live_settings

**`factory_seed.h`:** declare `void Factory_park_live_settings(void);`

**`factory_seed.c`:** implement like Linux cmd-061:
- Resolve line from `G_major_version`; if major not in 1…8, log warn and return.
- `live = My_getenv("HOME")`; missing live → warn + return.
- `ensure_cal_line_dir(live, line)`.
- For each of `iq.ini`, `power_cal.ini`, `amplifier_cal.ini`: if live file exists, `copy_file` to `live\cal\<line>\<name>` (Windows `\\` paths — match existing helpers); missing live = skip + warn log; copy fail = warn log.
- `write_last_line(live, line)`.
- Log `Factory_park. done line=… major=… files=N`.
- Reuse existing static helpers; **no** continuous mirrors; **no** exit auto-park; **do not** move `power_cal.ini` ownership (copy only).

**`usbavrcmd.h`:** `#define CMD_SET_PARK_CAL_SETTINGS 0x29` (near other client→ms-sdr sets; keep clear of `0x28`).

**`main-controller.c` `Command_Interface`:**  
`case CMD_SET_PARK_CAL_SETTINGS:` → log + `Factory_park_live_settings();` `break;`  
Ignore payload or accept data=1. Prefer warning logs over stopping the radio.

Include `factory_seed.h` if the controller does not already.

Build/deploy ms-sdr to `C:\mscc-net9` (existing Windows build pattern from prior cmds). `VERSION_MINOR` auto-bump is fine.

### 2. Core — opcode + ParkCalSettingsAsync (if missing)

In `mscc-ui/windows-work-tree/mscc-mscc/mscc-new/src/MSCC.Core/`:

- `Protocol/Opcodes.cs`: `public const byte CMD_SET_PARK_CAL_SETTINGS = 0x29;` (+ XML note: park live iq/power/amplifier for current line; payload 1). Name map is reflection-based — constant alone is enough.
- `Services/IRadioService.cs`: `Task ParkCalSettingsAsync(CancellationToken cancellationToken = default);` — ask host to park; no-op if session not started.
- `Services/UdpRadioService.cs`: if `!_started` return; else `SendAsync(Opcodes.CMD_SET_PARK_CAL_SETTINGS, (short)1, …)` + short monitor text.

Match Avalonia/Linux contract so one client binary works against Windows or Linux hosts that implement 0x29.

### 3. WPF Save settings → host 0x29

**`MainWindow.xaml.cs` `SaveSettings_Click`:**
- Keep major/line check (may use `CalPark.TryLineFromMajor` **only** for the human line name in dialogs — not for file copy).
- If not connected / session not started / major unknown → **warning** MessageBox (connect radio first). Do not pretend success.
- If OK → `await ViewModel.RadioService.ParkCalSettingsAsync()` (make handler `async void` or follow existing async click patterns).
- Info MessageBox: host was asked to park live cal for line `<line>`. Optional: mention park lives on the **connected host**, not this PC's AppData when remote.
- **Do not** call `CalPark.SaveLiveToParked`.

**`MainWindow.xaml`:** ToolTip on Save settings → `Ask the host to park live cal for this radio.`  
Keep on-tab tips `When done, press Save settings.` (cmd-059).

**`CalPark.cs`:** Remove `SaveLiveToParked` (and unused helpers only used by it) so there is **no** dual client park path. Keep `TryLineFromMajor` / `ParkFiles` only if still useful for UI labeling; otherwise slim the class. Do **not** add a new client-side park substitute.

WPF version: calendar auto-bump on build (`ClientVersion.txt`).
