## Outcome

Ship the repo-root `factory/` tree (per-line IQ / freq / power templates) inside both Ubuntu and Pi `mscc` servers packages at:

```text
/usr/share/mscc/factory/iq/<line>/iq.ini
/usr/share/mscc/factory/freq/<line>/freq_cal.ini
/usr/share/mscc/factory/power/<line>/power_cal.ini
```

Lines (must match Windows / repo `factory/`): `proficio-legacy`, `proficio-mkii`, `geminus-legacy`, `geminus-mkii`, `ultimus-legacy`, `ultimus-mkii`.

This mirrors Windows layout (`factory/<kind>/<line>/…` next to the exe on Windows; package share on Linux). Package upgrades may refresh `/usr/share/mscc/factory/`. Package install/upgrade must **never** overwrite `~/.local/mscc/` live files or any future `~/.local/mscc/cal/<line>/` parked set.

**Phase 1 is files-only packaging.** Do **not** add runtime seed/park/restore code. Do **not** change postinst to copy factory into live. Flat `init-files` first-boot seed stays as today until phase 2.

## The change

### 1. Stage factory into the Ubuntu amd64 deb

In `linux-build/build-mscc-deb-amd64.sh`:

- Set `FACTORY_SRC="$ROOT/factory"` (repo-root `factory/`).
- `need_dir "$FACTORY_SRC"` and probe at least one file (e.g. `$FACTORY_SRC/iq/proficio-mkii/iq.ini`).
- When wiping/recreating stage dirs, also reset `"$PKG/usr/share/mscc/factory"` (same pattern as `init-files`).
- `mkdir -p "$PKG/usr/share/mscc/factory"`
- `cp -a "$FACTORY_SRC/." "$PKG/usr/share/mscc/factory/"`
- Do **not** copy `factory/README.md` requirement either way — shipping it is fine; omitting it is fine. Prefer shipping the whole tree as-is (including README) so layout stays identical to the repo.
- Keep existing `init-files` staging unchanged.

Bump `linux/mscc-deb/packaging/DEBIAN/control` **Version: 1.0.47 → 1.0.48**.

### 2. Stage factory into the Pi arm64 deb (packaging path only)

In `rpi/mscc-deb/build-deb.sh`:

- `FACTORY_SRC="$TREE/../factory"` (repo-root `factory/` from `rpi/`).
- Same `need_dir` / probe / wipe / `mkdir` / `cp -a` as Ubuntu.
- Keep `init-files` staging unchanged.

Bump `rpi/mscc-deb/packaging/DEBIAN/control` **Version: 1.0.50 → 1.0.51**.

### 3. postinst / postrm / runtime — do not change

- **Do not** edit `postinst` to seed from factory into `~/.local/mscc/`.
- **Do not** edit ms-sdr / sdrcore-trans / Avalonia.
- **Do not** remove flat `iq.ini` / `freq_cal.ini` / `power_cal.ini` from `init-files` (still the first-boot seed until phase 2).
- Document in the report: init-files = flat first-boot seed; `/usr/share/mscc/factory/` = per-line package factory for phase 2+; phase 2 will decide which wins for brand-new radio lines.
